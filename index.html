Perpus & Ruang Belajar

🌐 Modul Jaringan Komputer

Dokumentasi konfigurasi, topologi, dan analisis protokol jaringan Informatika Kelas XII

Modul 01

Konfigurasi IP Address & Subnetting

Praktikum pengalamatan IP v4 Static, perkhitungan Subnet Mask Class C, dan pengujian konektivitas antarnode menggunakan perintah `ping` dan `traceroute`.

# Pengujian Konektivitas $ ipconfig /all $ ping 192.168.10.1 -t Reply from 192.168.10.1: bytes=32 time=1ms TTL=64
Modul 02

Simulasi Topologi Cisco Packet Tracer

Rancangan topologi jaringan Bintang (Star) menghubungkan Switch Layer 2, Router Mikrotik/Cisco, Server DHCP, dan 10 PC Client sekolah.

Modul 03

Analisis Protokol dengan Wireshark

Pengamatan lalu lintas paket data HTTP, DNS Query, dan pengujian proses Tiga-Langkah (Three-Way Handshake) protokol TCP pada jaringan lokal.

🤖 Modul Internet of Things / Arduino

Dokumentasi sirkuit, kode program C/C++, dan eksperimen sensor mikrokontroler

Simulasi Wokwi

Sistem Pemantau Suhu (DHT11 + LCD I2C)

Membaca data suhu dan kelembapan udara menggunakan sensor DHT11 lalu menampilkan hasilnya pada layar LCD 16x2 dengan komunikasi I2C.

#include <DHT.h> #include <LiquidCrystal_I2C.h> #define DHTPIN 2 #define DHTTYPE DHT11 DHT dht(DHTPIN, DHTTYPE); void setup() { dht.begin(); }
Aktuator

Kontrol Servo & Sensor Ultrasonik

Simulasi palang pintu otomatis berbasis jarak benda yang dideteksi oleh Sensor HC-SR04 dan diproses oleh Motor Servo SG90.

IoT Web

ESP8266 Wi-Fi Web Server Smart Relay

Pengendalian modul Relay sakelar lampu jarak jauh menggunakan modul ESP8266 NodeMCU melalui browser web smartphone.
